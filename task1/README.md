# Домашнее задание №1  
## CLI-инструмент для получения информации о репозитории GitHub

---

## Функциональность

CLI-инструмент получает информацию о репозитории GitHub в определённом формате (имя репозитория и автор) и выводит её в консоль.

---

## Выводимая информация

1. Имя репозитория  
2. Описание  
3. Количество звёзд  
4. Количество форков  
5. Дата создания  

---

## Сборка
Из task1
`go build`

## Запуск
Из task1
`./github_info <owner> <repo>`
Например,
`./github_info golang go`
